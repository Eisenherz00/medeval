# Examples

This directory contains example notebooks and scripts demonstrating how to use MedEval.

## Structure

- `basic_usage.py`: Basic examples of using core functionality
- `nifti_spacing.py`: Examples of working with NIfTI files and spacing
- `aggregation.py`: Examples of metric aggregation and confidence intervals

## Running Examples

Examples can be run directly:
```bash
python examples/basic_usage.py
```

Or in a Jupyter notebook environment for interactive exploration.
